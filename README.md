# 最期の一日

ある人の、最後の一日を一人称で過ごす 3D の体験です。誰の、どんな一日になるかは毎回ランダムに決まります。
朝の場面から最期の時刻まで、時計は進みつづけます（語りが出ているあいだと、場所を移るあいだだけ止まります）。最期の時刻が来るまでは、歩く、人に話しかける、思い出の品を見つめる、腰をおろす、目を閉じる。どれも自由にできます。

- 最期のパターン 540 件（病気 270、事故 162、災害・気象 54、老衰 54）。自死・他殺・戦争は入れていません。
- 一日のうち 3 つの時刻に、その場面の語りが入ります。思い出の品にともる灯を見つめると、その人の人生の記憶を古い順に思い出します（記憶 389 件、最後の一言 70 件）。
- 一時間を何分で過ごすかは、1〜5 分から選べます（はじめの画面と、体験中の右上）。朝から最期まではふつう 12 時間ほどなので、2 分なら 24 分前後の体験になります。
- そばの人やその場にいる人に話しかけると、短いやり取りが返ります（会話 190 件。続柄・役・時刻・季節・天気・体の状態で出し分け）。
- 場所は 19 種（自宅の和室・居間・寝室・浴室、病室、集中治療室、緩和ケア病棟、介護施設、事務室、店、工事現場・工場、通り、広場、電車、車、田畑、山、川、海・船）。時刻・季節・天気で光と音が変わります。
- 人物と木は Blender で作ったモデルです（骨つきの人物 1 体と髪型 5 種、木 6 種 × 2 本）。手は、指 1 本ずつに関節が 3 つあり、力を抜いた手・握った手・のばした手に曲がります。自分の体も同じ人物モデルで、手を置く位置から腕の曲げ方を計算し、手首のひねりは前腕にも配っています。

## 流れる一日

一日の進み方は `src/js/45_day.js` にあります。

**時計。** 時刻は分の単位で数え、1 秒に「1 ÷ 設定の分数」分ずつ進みます。日ざし、空の色、明かり、壁の時計の針、まわりの音は、この時刻に合わせて変わりつづけます。場面の語りが出ているあいだと、場所を移るあいだだけ、時計を止めます。

**出来事。** パターンの 3 つの場面（`beats`）と最期（`end`）を、時刻の順に並べて予定にします。

| 出来事 | 何が起きるか |
|---|---|
| 場面の語り | その時刻になると、語りが出る。同じ場所にいれば、いまいる所でそのまま聞く（姿勢がちがうときだけ、まばたきひとつで移る） |
| 場所の移り | まぶたが閉じ、時刻と場所の札が出て、次の場所で目をあける |
| たどれない時間 | 勤め先や学校にいる時間、家から病院へ運ばれて処置を受けるあいだなど、場面のデータがない時間は、目を閉じているうちに時計だけが進む |
| 最期 | 場所が同じなら、まぶたも閉じず、いまいる所でそのまま始まる。歩いている人は、異変が来る瞬間まで歩ける。話や思い出の途中なら、そこで断ち切られる |

移る時刻は、場所ごとの長さの目安（`STAY` と `EARLY`）で決めています。通り・店・電車・車・浴室・広場には長くいられません。家や病室は、次の語りの何時間も前から過ごせます。

**自由にできること。**

- 歩く。場所ごとの `walk`（床の長方形）をマス目に切り、足もと 0.3 m から頭 1.55 m までに物があるマスを自動で除きます（`src/js/25_nav.js`）。壁や家具に当たると、壁ぞいにすべります。歩く速さは年齢と体の具合で変わります。もう長くないと分かっている人、老衰の人、75 歳をこえた人は、歩きつづけると息が上がります（思いもよらない最期の人には、それ以外の前ぶれを足しません）。
- 歩けない人もいます。病室・施設・車の中、寝ついている人（`aware` か老衰で、横になっている場面）、車椅子や寝たきりの人（データの `bound`）、急な発症のあとは、見まわす・話す・目を閉じる、だけです。声を出せない人（データの `mute` と、集中治療室）は、相手に目を向けるだけで、こちらからは言葉をかけません。
- 座っている・横になっている場面では、歩こうとすると立ち上がります。椅子やベンチでは腰をおろせます。寝床のそばでは横になれます。
- 人に話しかける。話しかけられるのは、付き添っている身近な人、その場にいる人（同僚、店の主人、客、仕事仲間、看護師、乗り合わせた人、広場に居合わせた人）、立ち寄る人（近所の人、まわってくる看護師や職員）です。相手は顔をこちらへ向けて答えます。
- 思い出の品。灯は、その場所にある物（写真立て、壁の時計、庭の木）にともります。見つめると物の名前が出て、記憶が語られます。
- 目を閉じる。閉じているあいだは、1 秒に 10 分進みます。次の出来事の前に、ひとりでに目がさめます。寝ついている人は、何も操作しないでいると、うとうとします。夜、横になっていれば眠ります。

**時刻ごとの出来事。** 病棟の配膳車と消灯、町の正午と夕方のチャイム、子どもたちの声などが、決まった時刻に音と 1 行で入ります（`data/life/day.json`）。看護師や職員は日に 4〜5 度（集中治療室では 2 時間おきに）まわってきて、近所の人は昼のあいだに一度、顔を見せに来ます。人が来るときと帰るときは、まばたきのあいだに現れ、消えます。

## 最期の場面の運び

最期の場面（`src/js/41_dying.js`）は、死因の性質で 4 つの運び方に分かれます。どれになるかは、パターンの `cat`・`aware`・`end.fx`・`end.stage`・`end.state` から決まります（540 件の内訳: 引いていく 284、断ち切られる 120、体の中で起きる 87、まわりに呑まれる 49）。

| 運び方 | 当てはまるもの | 何が起きるか |
|---|---|---|
| 断ち切られる | 衝突・落下・落下物（`impact`。病室が最期の場所のときは除く） | いつものように灯がともり、見つめているうちに、予告なく最期が来る。語りは読みきる前に切れ、白い光、暗闇、無音。耳鳴りだけが先に戻り、にじんだ横倒しの景色がゆっくり動く。目の前の地面に、自分の手がある。まわりの声は遠く、救急車の音は近づききらない |
| 体の中で起きる | 胸・頭の急な発作（`chest` `head`、本人は知らない）と、急に倒れる病気（`state` に `arrest` か `weak` がある件。心室細動、大出血など。病室が最期の場所のときは除く） | 語りを読んでいる途中で来る。胸のときは鼓動がひとつ抜け、体が前に折れ、手が胸へ行く。頭のときは光と音の切れで始まり、手が額へ行く。そばに人がいれば、顔を向け、寄ってきて、手を取る |
| まわりに呑まれる | 水・煙（`water` `smoke`）、のどに物が詰まる窒息（`state` の `choke`） | 水では、水の中の色になり、泡が上がり、明るいほうへ手をのばす。煙では、せきこみ、身を低くする。のどが詰まったときは、息の音が出ず、手がのどへ行く。意識のないまま呑まれるとき（入浴中、就寝中の火災）は、もがかない |
| 引いていく | 眠るような最期、病気の終わり、老衰 | 息の音をひとつずつ鳴らし、息と息のあいだが少しずつのびる（急な息苦しさは、浅く速い息から始まる）。本人が分かっている最期（`aware`、`sleep`、老衰）では、長いまばたきのたびに時刻が進み、そばの人が近くなっている。人工呼吸器がついているとき（`state` の `vent`）は、機械の一定の息が最後まで続く |

終わり方には 2 つの順があります。

- ふつうは、視界が先に暗くなり、息が止まり、鼓動はそのあともしばらく続いて、打つ間隔がのびていきます。
- 心臓が先に止まる最期では、鼓動が先に消え、あえぐような息はそのあとに出ます。あえいでいても心臓は止まっている、という順です。どの件がこれに当たるかと、鼓動の消え方は、病名からの推測ではなく、パターンごとに `end.state` に書いてあります（`arrest` こまかく乱れて消える: 心筋梗塞、心室細動など 36 件 / `weak` 速いまま弱くなって消える: 大動脈解離、肺血栓塞栓症、大出血など 21 件 / `brady` 遅くなって止まる: 房室ブロックなど 6 件）。場面の途中の鼓動の速さも、この印に合わせています。

どちらも、音がいちばん最後に遠のきます。聴覚は最後まで残るといわれることからの演出です。本人に聞こえているかどうかは、確かめられていません。集中治療室では、鼓動が消えたあともモニターの拍の音がまばらに続き、それから警報が鳴って、やがて誰かが止めます（心室細動のときは、すぐに警報が鳴ります）。暗くなったあと、その場所でその後も続いていること（信号、波、廊下の足音）を 1〜2 行だけ出してから、おわりの画面へ進みます。

- 本人がもう長くないと分かっている一日（`aware`）は、朝・昼・夕と進むにつれて、視野のはしがわずかに暗くなり、息の音が聞こえはじめます。思いもよらない最期の一日は、最後の瞬間まで何も変えません。
- 最期の場面で出す短い言葉（体の感じ、まわりの声、暗くなったあとの 1〜2 行）は `data/life/ending.json` にあります。最期の語りに同じ言葉が出てくるときは、重ねて出しません。
- 画面の動きを減らす設定（OS の「視差効果を減らす」）のときは、光・揺れ・傾きを弱めます。光るのは 1 回だけで、点滅はしません。

## 開き方

`index.html` をブラウザで開くだけで動きます（オフライン可。音は「はじめる」を押してから鳴ります）。
プレビュー: `~/Applications/.claude/launch.json` の `saigo-no-ichinichi`（port 9151）。

## 操作

- 見まわす: ドラッグ（スマホはなぞる）、または矢印キー
- 歩く: W A S D（スマホは左下の円）。座っているときは、歩こうとすると立ち上がる。通りでは、赤信号のあいだは横断歩道へ出られない
- 話しかける・腰をおろす・横になる: 相手や場所を見て E（またはクリック、Space。スマホは画面を軽く押す）
- 記憶をたどる: ともった灯を見つめる。灯をタップするか「灯を見る」でも可
- 目を閉じる・あける: C、または「目を閉じる」
- 語りを先へ進む: クリック、Space、Enter、「つづける」
- 一時間の長さを変える: 右上の「一時間 二分」を押すたびに、1 分ずつ変わる
- やめる: 右上の「やめる」、または Esc

## 作り直し

```bash
python3 build/assemble.py          # src/ と data/ から index.html を組み立てる
python3 data/validate.py --all     # 最期のパターンの書式を点検する

# 人物と木のモデルを作り直すとき（Blender 5.2 で確認。画面は開かない）
/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup -P blender/build_assets.py
#   確認用の画像も出す:  … -P blender/build_assets.py -- --preview 出力フォルダ
```

モデルを作り直したら、`build/assemble.py` をもう一度動かします（`assets/kit.glb` を `index.html` に埋め込むため）。

| 場所 | 中身 |
|---|---|
| `src/js/` | 本体。番号順につなぐ（土台 20〜23、モデルの読み込みと差し替え 24、歩ける範囲 25、場所 30〜37、効果 31、音 32、画面 40、最期の場面の運び 41、流れる一日 45、進行 50、起動 90） |
| `blender/build_assets.py` | 人物と木のモデルを作るスクリプト。数値を直して動かすと `assets/kit.glb` を書き出す |
| `assets/kit.glb` | 書き出したモデル（約 1.3MB）。読み込めないときは、手組みの形（22・23）のまま動く |
| `src/tokens.css` `src/style.css` | 色・文字・余白の決まりと、画面のスタイル |
| `data/causes/*.json` | 最期のパターン。書式は `data/SPEC.md` |
| `data/life/*.json` | 人生の記憶と最後の一言、最期の場面の短い言葉（`ending.json`）、会話（`talk.json`）、時刻ごとの出来事（`day.json`）。書式は `data/SPEC_life.md` |
| `build/fix.py` | id を指定して文章をまとめて直すツール |
| `vendor/` | three.js r185 を 1 本にまとめたもの（MIT ライセンス。`vendor/LICENSE-three.txt`） |

## 確認用の URL

- `?id=hrt-001` そのパターンで始める／`&seed=5` 人物を固定／`&fast=4` 文字送りを速く／`&auto=1` すぐ始める
- `?stage=washitsu&pos=lie&t=07:30&season=spring&weather=clear` 場所だけ見る（`&with=1` 付き添い、`&spots=1` 灯の場所）
- `?show=epi` `?show=ledger` `?show=mem` `?show=narr` 各画面だけ見る
- `?id=trf-012&end=1&auto=1` 最期の場面から始める（`&dbg=1` で、いまどの段かを画面に出す）
- `?selftest=ends` 最期の場面 540 件を、待ち時間なしで端から通す試験（結果は画面に出る）
- `?selftest=day` 朝から最期まで 540 件を、時計を早回しにして通す試験。途中で、話す・思い出す・立つ・座る・目を閉じるを手あたりしだいに試す（`&from=0&n=180` で区切れる）
- `?id=trf-001&auto=1&hour=0.06` 一時間を 0.06 分（約 4 秒）にして、一日の流れを早回しで見る
- `?id=hrt-001&auto=1&do=t1,w2,face,use,t6,seat,use` 操作を台本で流す（画面なしのブラウザで、歩く・話す・座るを確かめるため）。`w3` 3 秒歩く（`a` `s` `d` も同じ）/ `yaw90` 向きを変える / `face` いちばん近い人を見る / `seat` 腰をおろせる場所を見る / `light` 灯を見る / `use` 押す / `doze` 目を閉じる・あける / `visit` 近所の人を呼ぶ / `round` 看護師や職員を呼ぶ / `at10:30` 時計を進める / `t2` 2 秒待つ
- `?stage=living&top=1` 場所を真上から見て、歩けるマス（緑）、視点、灯の場所と品の名前、人の位置を重ねる（`&span=40` 横幅、`&cx=0&cz=10` 中心、`&v=factory` 種類）
- `?stage=park&figs=stand`（または `figs=sit`）人物を目の前に並べる／`&bodies=lie,lieUp,sit,car,bath,stand` 自分の体を外から見る／`&noassets=1` モデルを使わない
