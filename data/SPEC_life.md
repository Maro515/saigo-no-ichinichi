# 「最期の一日」 人生の記憶の書式

一人称視点の 3D 体験アプリ「最期の一日」で使う、人生の記憶の書き方です。
アプリは 1 回ごとに、年齢・仕事・家族の違う「ある人」を作り、最後の一日の合間に、その人の記憶を古い順に 6 つほど思い出させます。
ここで書くのは、その記憶の 1 つ 1 つです。誰の人生にも当てはまるように、条件（年齢、家族、生まれ年、仕事）をつけて書きます。

## 記憶 1 件の形

```json
{"id": "ma-001", "stage": "child", "text": "父の自転車の荷台で、背中にしがみついていた。シャツが汗でしめっていた。坂の上まで来ると、屋根のむこうに海が見えた。"}
{"id": "ma-002", "stage": "child", "born": [1955, 1972], "text": "駄菓子屋の軒先で、十円玉を握って迷っていた。くじの紙をなめると、赤い字が浮いてくる。はずれだった。"}
{"id": "mb-010", "stage": "kids", "need": ["kids"], "text": "夜中に熱を出した子どもを抱いて、台所を行ったり来たりした。小さな背中が、手のひらより熱かった。"}
{"id": "md-003", "stage": "work", "job": "fishery", "text": "夜明け前の港は、氷の音がする。網を上げると、甲板いっぱいに銀色がはねた。指は、冬じゅう割れていた。"}
```

| 項目 | 内容 |
|---|---|
| `id` | 担当ごとの接頭辞＋3 桁の連番 |
| `stage` | 人生のどの時期の記憶か。下の表から選ぶ |
| `text` | 記憶の本文。50〜130 字。2〜3 文 |
| `min` | （任意）この記憶を持てる最低の年齢。本文から年齢の下限が読みとれるときに書く（「還暦の祝い」なら 61） |
| `max` | （任意）この記憶を持てる最高の年齢。`joy` で子どもや若い人だけの内容のときに書く |
| `need` | （任意）家族の条件。`partner` 連れ合いがいた / `widowed` 連れ合いに先立たれた / `kids` 子どもがいる / `grandkids` 孫がいる。配列で書く |
| `born` | （任意）`[から, まで]` の生まれ年。本文に時代のもの（白黒テレビ、ファミコン、スマホなど）が出るときは必ず書く。今は 2026 年 |
| `job` | （任意）`stage` が `work` で、その仕事の人だけの記憶のとき |
| `sex` | （任意）`f` / `m`。出産など、どちらかに限るときだけ |

## 時期（stage）

| stage | 時期 | アプリが使う相手 |
|---|---|---|
| `child` | 幼いころ（〜12 歳くらい） | 全員 |
| `teen` | 十代（中学〜高校のころ） | 16 歳以上 |
| `young` | 若いころ（19〜29 歳くらい。進学、ひとり暮らし、就職、旅、友だち） | 24 歳以上 |
| `love` | 連れ合いとのこと（出会い、結婚、ふたりの暮らし） | 24 歳以上で、連れ合いがいた人。`need` に `partner` を必ず書く |
| `work` | 仕事 | 22 歳以上。学生は除く |
| `kids` | 子どものこと | 子どもがいる人。`need` に `kids` を必ず書く |
| `mid` | 人生のなかば（40〜60 代のできごと） | 52 歳以上 |
| `loss` | 別れ（親、連れ合い、友、飼っていた生きものの死） | 40 歳以上 |
| `late` | 老いてから（70 歳以降の暮らし） | 72 歳以上 |
| `joy` | このごろの小さな喜び（今の暮らしの中の、ささやかなこと） | 全員。年齢に合わないものは `min` `max` で絞る |

## 書き方

1. **一人称・過去形**で書く（`joy` だけは現在形でもよい）。主語（わたし、僕、俺）は書かない。
2. その場の**見えたもの・音・におい・手ざわり**を書く。「幸せだった」「つらかった」と気持ちを説明しない。大きなできごとより、小さな一場面を。
3. 人の名前は書かない。父、母、祖母、兄、友だち、先生。連れ合いは **「あの人」**（男女どちらにも読めるように。妻・夫・彼・彼女と書かない）。子どもは「子ども」「あの子」（息子・娘と書かない。人数も決めない）。孫は「孫」。
4. 本人の性別が決まる書き方をしない（学ラン、振袖、化粧、ひげ、など）。どうしても要るときだけ `sex` をつける。
5. 住んでいる土地を決めすぎない。実在の地名、学校名、商品名、人名は書かない（「ファミコン」「ラジオ体操」のような、時代を表す一般的な呼び名は可）。
6. 時代のものを書くときは、`born` の幅を正しく計算する。たとえば「小学生のころ、白黒テレビが家に来た」なら 1948〜1958 年生まれくらい。全体の 6 割以上は、時代を問わない内容（`born` なし）にする。
7. 明るい記憶ばかりにしない。叱られた、言えなかった、間に合わなかった、という記憶も混ぜる。ただし虐待、暴力、性的な内容、自死は書かない。
8. 似た場面を繰り返さない。1 件ごとに違う小道具・違う場所・違う季節にする。
9. 「〜を行う」「〜において」「〜することができる」は使わない。ふつうの言葉で書く。

## 最後によぎること（last.json）

最期の瞬間に、ふと頭をよぎる一言です。大げさな言葉ではなく、小さなことを書きます。

```json
{"id": "lt-001", "text": "洗濯物を、取り込んでいない。"}
{"id": "lt-002", "text": "あの人のいれたお茶を、もう一度飲みたかった。", "need": ["widowed"]}
{"id": "lt-003", "text": "宿題、まだやっていないのに。", "max": 18}
```

- `text` は 8〜40 字。1〜2 文。
- `min` `max` `need` は記憶と同じ。
- 半分はごく日常のこと（やりかけの家事、読みかけの本、明日の予定）。残りは、礼、心残り、ふと思い出す景色。

## 最期の場面の短い言葉（ending.json）

最期の場面で、語り（`end.lines`）のあいだに出す短い言葉です。配列ではなく、3 つの項目を持つ 1 つのオブジェクトです。

| 項目 | 中身 |
|---|---|
| `sense` | 体の感じ。効果のタグ（`impact` `chest` `head` `breath` `water` `smoke` `cold` `heat` `sleep` `fade` `fall`、のどが詰まったときの `choke`）ごとの配列。視野のはしに縦書きで浮かぶ |
| `voice` | 声。`bystander` 通りがかりの人 / `alarm` そばの人（急なとき） / `vigil` そばの人（看取り） / `farewell` 別れぎわ / `staff` 病棟や施設の人 / `icu` 集中治療室の人 / `rescue` 居合わせて助けようとする人（急に倒れたとき、のどが詰まったとき）。かぎかっこは付けない（画面で付く） |
| `after` | 暗くなったあとに出す、その場所でその後も続いていること。場所（`stage`）ごとの配列。`held` は、手を握られたまま終わったときの 1 行 |

`sense` と `after` の 1 件は `{"t": 文, "if": 条件, "k": [語...], "late": true}` です。

- `t` は 3〜20 字の 1 文。現在形で、本人の感じたままを書く（説明しない）。病名や診断が決まる書き方をしない。
- `k` は、その文の芯になる語。最期の語りに同じ語があれば、その文は出さない（同じことを 2 度言わないため）。
- `late` をつけると、場面の後半にだけ出る。
- `if` はカンマ区切りで、すべて当てはまるときだけ出る。`out` 屋外 / `in` 屋内 / `fall` 倒れたあと / `env` 事故・災害 / `ill` 病気・老衰 / `day` 昼 / `dawn` 明け方 / `clear` 晴れ / `sudden` 急な最期 / `self` 自分で息をしている（人工呼吸器の件、のどが詰まった件では出さない） / `awake` 意識がある（眠ったまま、気を失ったまま呑まれる件では出さない） / `exposed` 寒さにさらされている（事故・災害で、水の中・屋外・低体温の件） / `v:city|highway` `v:mountain` `v:boat` 場所の種類。
- 声の `{呼び名}` は、そばの人が本人を呼ぶ名、`{名}` は本人の名、`{大切な人}` は続柄に置きかわる。
- `after` は、その場所ならまず起きていることだけを書く。その人の持ち物や、その日の出来事には頼らない（「ラジオが鳴っている」のように、あったかどうか分からない物は書かない）。
- このファイルは配列ではないので、下の点検スクリプトの対象外。JSON として読めることと、`python3 build/assemble.py` が通ることを確かめる。

## 会話（talk.json）

一日のあいだ、人に話しかけたときに出る短いやり取りです。配列ではなく、`close`（いちばん身近な人）と `folk`（その場にいる人）を持つ 1 つのオブジェクトです。

- `close` は続柄ごと（`spouse` 夫・妻 / `child` 娘・息子 / `grandchild` 孫 / `parent` 母・父・祖母 / `sibling` 妹・弟 / `niece` 姪・甥 / `friend` 友人）に、`daily`（ふだんの一日）と `care`（寝ついている人のそば）の 2 つの配列を持つ。
- `folk` は役ごとの配列（`neighbor` 近所の人 / `passerby` 通りがかりの人 / `cook` 店の主人 / `customer` 客 / `coworker` 同僚 / `worker` 仕事仲間 / `nurse` 看護師 / `icunurse` 集中治療室の看護師 / `carer` 介護施設の職員 / `hospicenurse` 緩和ケア病棟の看護師 / `passenger` 乗り合わせた人 / `child` 子ども / `parkgoer` 公園の人）。
- 1 件は `{"me": 本人の言葉, "re": 相手の返事, "if": 条件}`。`me` は 16 字以内で、誰が言っても不自然でない言葉にする（省くと「声をかける。」とだけ出る）。`re` は 34 字以内。かぎかっこは付けない（画面で付く）。
- `if` はカンマ区切りで、すべて当てはまるときだけ出る。`morning` 5〜10 時 / `noon` 10〜15 時 / `evening` 15〜19 時 / `night` 19〜5 時 / `spring` `summer` `autumn` `winter` / `clear` `cloudy` `rain` `snow` / `day` 10〜18 時（「こんにちは」が合う時間） / `late` 21〜5 時 / `kid` 本人が 15 歳以下 / `grown` 19 歳以上 / `old` 75 歳以上 / `home` 自宅にいるとき（家の物に頼る台詞に付ける） / `ward` 病室・施設にいるとき / `up` 本人が起きている / `abed` 横になっている / `meal` 食事のすぐあと / `mild` 窓をあけられる気候（雨や雪でなく、冬でなく、昼間） / `dry` 雨や雪でない。
- `{呼び名}` は `close` の `re` だけ、`{名}`（本人の名）は `folk` の `re` だけで使える。
- `daily` では、本人も相手も、今日が最期だと知らない。ごくふつうの会話にする。`care` は、病室・施設にいる人と、寝ついている人のそばで出る。励ましや別れの決まり文句を書かない。**口から飲む・食べることをすすめる台詞は書かない**（絶飲食の人、飲みこめない人にも出るため。口のかわきには、くちびるをしめらせる、と書く）。花や食べ物の持ちこみは、自宅だけにする（`home`）。看護師や職員には、病名、薬の名前、検査値、治る・治らないを言わせず、本人を下の名前で呼ばせない。
- 声を出せない人（パターンの `mute` と、集中治療室）には、`me` のない台詞だけが出る。各枠に `me` のない台詞を 2 つ以上入れておく。

## 時刻ごとの出来事（day.json）

- `world` は、決まった時刻に入る出来事の配列。1 件は `{"t": "HH:MM", "in": [場所...], "text": 1 行, "snd": 音, "arg": 音の種類, "if": 条件}`。`in` の場所にいるときだけ出る。`snd` は `tune`（町のチャイム。`arg` は `noon` か `evening`）/ `cart`（配膳車）/ `kids`（遠くの子どもたちの声）。`if` は会話と同じ語に加えて、`dry`（雨や雪でない）、`out`（屋外）が使える。
- `notes` は、人が来たとき・帰るときの 1 行。役（`neighbor` `nurse` `hospicenurse` `carer`）ごとに、`home` 自宅 / `out` 外 / `care` 病室・施設 / `leave` 帰るとき。
- その場所ならまず起きていることだけを書く。その人の持ち物や、家族のあるなしには頼らない。

## ファイルと点検

- 出力は JSON の配列 1 つ。UTF-8。コメントや末尾のカンマは入れない。
- 書き終えたら、必ず点検スクリプトを通し、エラーが 0 になるまで直す。

```bash
python3 data/validate_life.py data/life/<ファイル名>.json --prefix <接頭辞> --count <件数>
```
