# 「最期の一日」 最期のパターンの書式

一人称視点の 3D 体験アプリ「最期の一日」で使う、最期のパターン（死因ごとの一日）の書き方です。
1 件が「ある人の、最後の一日」です。朝から順に 3 つの場面（beats）があり、最後に最期の場面（end）が来ます。
アプリは場面と場面のあいだに、その人の人生の記憶（別データ）をはさみます。

体験に出すのは `data/focus.json` で選んだもの（事故・災害・事件と、病気の突然死）だけ。ほかのパターンもファイルには残してある。

## 1 件の形

```json
{
  "id": "hrt-001",
  "cat": "ill",
  "group": "心筋梗塞・狭心症",
  "name": "急性心筋梗塞",
  "place": "自宅の浴室",
  "age": [58, 86],
  "sex": "any",
  "season": "winter",
  "weather": "any",
  "aware": false,
  "beats": [
    {"t": "06:50", "stage": "living", "pos": "sit", "with": true,
     "text": "味噌汁の湯気で眼鏡がくもる。{大切な人}が、今夜は冷えるらしいよと言う。左の肩が少しこっているが、いつものことだ。"},
    {"t": "13:20", "stage": "street", "pos": "walk",
     "text": "郵便局まで歩く。坂の途中で息が上がって、電柱のところで一度立ち止まる。年だな、と思う。"},
    {"t": "19:10", "stage": "living", "pos": "sit", "with": true,
     "text": "夕飯のあと、テレビの天気予報が、明日の雪を告げている。先に風呂に入ることにする。"}
  ],
  "end": {"t": "19:40", "stage": "bath", "pos": "sit", "fx": ["chest", "fade"], "hit": 1,
    "lines": [
      "冷えた脱衣所から、熱い湯に肩まで沈む。",
      "胸の真ん中を、内側から握りつぶされる。",
      "声を出そうとしたが、息が入ってこない。",
      "湯の音が遠くなる。天井の水滴がひとつ、落ちてくるのが見えた。"
    ]},
  "note": "心筋梗塞は心臓の血管が詰まって起きる。冬の入浴は、脱衣所と湯の温度差で血圧が大きく変動し、発症のきっかけになることがある。"
}
```

## 項目

| 項目 | 内容 |
|---|---|
| `id` | 担当ごとの接頭辞＋3 桁の連番（`hrt-001`）。ファイルの中で重複させない |
| `cat` | `ill` 病気 / `acc` 事故 / `dis` 災害・気象・環境 / `old` 老衰 / `crm` 事件（被害にあう本人の目から） |
| `group` | 小分類。担当ごとに指定された語から選ぶ |
| `name` | 死因の名前。画面と過去帳に出る。28 字以内。同じ病名で状況が違うときは「急性心筋梗塞（雪かきのあと）」のようにかっこで区別する |
| `place` | 最期の場所。14 字以内。「自宅の浴室」「国道沿いの横断歩道」「緩和ケア病棟の個室」など。実在の施設名・地名は書かない（「北の山」「港町」のようにぼかす） |
| `age` | `[下限, 上限]`。この最期が起こりうる年齢の幅。下限は 10 以上、上限は 106 以下。場面と矛盾しない幅にする（運転は 18 歳以上、勤めは 18〜75 歳くらい、など） |
| `sex` | `any` / `f` / `m`。病気の性質上どちらかに限るときだけ `f` `m` |
| `season` | `any` / `spring` / `summer` / `autumn` / `winter`。本文に季節のものを書いたら、必ず合わせる |
| `weather` | `any` / `clear` / `cloudy` / `rain` / `snow` / `fog` / `storm`。本文に天気を書いたら、必ず合わせる |
| `aware` | 本人が「もう長くない」と分かっていれば `true`、思いもよらない最期なら `false` |
| `mute` | （任意）`true` なら、一日を通して声を出して話せない（気管の管、筆談、文字盤、重い構音の障害など）。人に話しかける場面で、本人の台詞を出さない |
| `bound` | （任意）`true` なら、一日を通して自分では立って歩けない（車椅子、寝たきり、麻痺）。病室・施設・車の中と、もう長くないと分かっている人（`aware`）や老衰の人が横になっている場面は、書かなくても歩けない扱いになる |
| `job` | （任意）仕事が決まっているときだけ書く。`office` 会社員 / `construction` 建設 / `factory` 工場 / `farm` 農業 / `fishery` 漁業 / `forestry` 林業 / `driver` 運転手 / `medical` 医療・介護 / `teacher` 教員 / `craft` 職人 / `shop` 商店・飲食 / `public` 公務員 / `art` 音楽・絵・文筆 / `home` 家事 / `student` 学生 |
| `beats` | ちょうど 3 つ。最期までの一日を時間の順に |
| `end` | 最期の場面 |
| `note` | 事実の説明。30〜130 字 |

### beats の 1 つ

| 項目 | 内容 |
|---|---|
| `t` | 時刻 `"HH:MM"`。時間の順に並べる。日付をまたぐのは 1 回まで（例: 08:00 → 15:00 → 22:30 → 最期 03:10） |
| `stage` | 場所。下の表から選ぶ |
| `pos` | 姿勢。`lie` 横になっている / `sit` 座っている / `stand` 立っている / `walk` 歩いている |
| `v` | （任意）場所の種類。下の表で `v` がある場所だけ |
| `with` | （任意）`true` なら、{大切な人}がすぐそばにいる。画面に人影が出る |
| `bound` | （任意）`true` なら、その場面だけ、自分では立って歩けない（はさまれている、支えられて座っている、急な病気で体が動かない） |
| `text` | その場面の語り。40〜130 字。2〜3 文 |

### end

| 項目 | 内容 |
|---|---|
| `t` `stage` `pos` `v` `with` | beats と同じ。`t` は 3 つめの beat 以降 |
| `fx` | 画面と音の効果。下の表から 1〜3 個 |
| `lines` | 最期の語り。3〜5 行。1 行は 10〜70 字 |
| `hit` | 異変が始まる行の番号（0 始まり）。その行から効果が強まっていく。眠るような最期は 0 |
| `see` | （任意）ドラマで見るとき、断ち切られる一瞬に見せるもの。本人の目に見えているときだけ書く（うしろから来る・暗くて見えないときは書かない）。`car-R` 右から迫る車のライト / `car-L` 左から / `car-F` 正面から / `car` 横から（左右はどちらでも） / `man` 振り向いた目の前に立つ人影（顔も凶器も見せない） |
| `state` | （任意）体の状態。当てはまるときだけ書く。`vent` 人工呼吸器がついている（自分の息の音は出さず、機械の一定の息が続く） / `still` 体を動かせない（鎮静や麻痺。手のしぐさを出さない） / `choke` 気道が完全にふさがっている（息の音を出さない） / `quiet` 意識のないまま水や煙に呑まれる（もがかない。入浴中や就寝中は書かなくても自動でこうなる） / 心臓が息より先に止まる最期は、止まり方をひとつ書く: `arrest` こまかく乱れて消える（心室細動など） / `weak` 速いまま弱くなって消える（大出血、心臓のまわりに血がたまる、肺の血管が詰まる） / `brady` 遅くなって止まる（房室ブロックなど） |

## 場所（stage）

| stage | 場所 | pos の意味 | v |
|---|---|---|---|
| `living` | 自宅の居間と台所（食卓、流し、テレビ） | sit 食卓 / stand 台所 / lie 床やソファ | |
| `washitsu` | 自宅の和室（畳、布団、障子、縁側、庭木） | lie 布団 / sit 縁側 / stand | |
| `bedroom` | 自宅の寝室（ベッド、窓、カーテン） | lie ベッド / sit ベッドの縁 / stand | |
| `bath` | 自宅の浴室 | sit 湯船 / stand 洗い場 | |
| `hospital` | 一般病棟の病室 | lie ベッド / sit 背を上げたベッド | |
| `icu` | 救急外来・集中治療室 | lie | |
| `hospice` | 緩和ケア病棟・ホスピスの個室 | lie / sit | |
| `facility` | 介護施設の居室 | lie / sit 車椅子 | |
| `office` | 職場の事務室 | sit 机 / stand | |
| `shop` | 飲食店・商店の店内 | sit 席 / stand | |
| `worksite` | 工事現場・工場 | stand / walk | `construction` / `factory` |
| `street` | 街の通り・交差点・駅前 | stand / walk | |
| `train` | 電車の車内 | sit / stand | |
| `car` | 車の運転席 | sit だけ | `city` / `highway` / `mountain` |
| `park` | 公園・校庭・運動場 | sit ベンチ / stand / walk | |
| `field` | 田畑・農道・里の道 | sit / stand / walk | |
| `mountain` | 山道・森・雪山 | sit / stand / walk | |
| `river` | 川・河原・用水路 | sit / stand / walk | |
| `sea` | 海辺・磯・船の上 | sit / stand / walk | `shore` / `boat` |

- 画面にはこの場所の 3D 空間が出ます。本文は、その場所にいて矛盾しないように書いてください（`hospital` の場面で海を歩かない）。
- 表にない場所（教室、体育館、飛行機、駅のホームなど）は、いちばん近い場所を選び、本文もそれに合わせます（校庭なら `park`、ホームなら `street`）。
- 倒れたあとの視点は `fx` の `fall` で表します。`pos` は倒れる前の姿勢を書きます。
- 雪・雨・夜は `season` `weather` `t` で自動的に変わります。

## 効果（fx）

| fx | 意味 |
|---|---|
| `chest` | 胸の痛み・圧迫。鼓動が乱れる |
| `breath` | 息が苦しい。呼吸が浅く速くなる |
| `head` | 激しい頭痛・めまい。視界がゆがむ |
| `fall` | その場に倒れる。視点が地面に落ちる |
| `impact` | 強い衝撃。一瞬の閃光と暗転 |
| `water` | 水の中。青く揺らぎ、音がこもる |
| `smoke` | 煙。視界が灰色にかすむ |
| `cold` | 寒さ。青白くなり、ふるえる |
| `heat` | 熱。白く飛び、ゆらぐ |
| `shake` | 揺れ。地震やけいれん |
| `sleep` | 眠るように。ゆっくりまぶたが閉じる |
| `fade` | 意識が遠のく。視界が暗く狭くなる |

## 書き方

1. **一人称・現在形**で書く。主語（わたし、僕、俺）はなるべく書かない。どうしても要るときは「わたし」。
2. 短い文で、見えるもの・聞こえるもの・手ざわり・においを書く。気持ちの説明や教訓は書かない。
3. 1 件ごとに、その人だけの**小さな具体物**を 1 つ入れる（炊飯器の予約、手の甲のメモ、乾ききらない洗濯物、など）。ほかの件と同じ小道具を使い回さない。
4. 家や出先の場面のあとに病院・集中治療室の場面が続くとき、前の場面の語りに「救急車」「電話に向かって」「痛みが来る」「痛みが走る」「動けなくなる」「立っていられない」「息もつけない」「板のように硬」「締めつけられ」「はさまれて動かない」のどれかがあると、アプリは「急な発症のあと、すぐに運ばれる場面」として扱う（歩けず、会話も出ず、12 分で目を閉じる）。発症を書く場面では、このどれかの言い方を使う。ふつうの場面では使わない。
5. beats は「最後のふつうの一日」。思いがけない最期では、3 つとも予兆にしない。ごくふつうの朝と昼を書く。長く患っている人は、病室や自宅での一日でよい。
6. **むごい描写はしない**。傷・血・体の損なわれ方をくわしく書かない。感覚が遠のいていく様子で終える。死んだあとのことは書かない。
7. 最期の行は、静かに終える。説明で締めない。
8. **医学的に正しく**書く。症状・経過・年齢・場所がその病気やけがと矛盾しないこと。`note` は一般に確立した事実だけを書き、確かでない数字や割合は書かない。
9. 自死、戦争、虐待、医療者や特定の誰かを責める内容は書かない。事件（`crm`）は、被害にあう本人の目から書き、加害者の顔や手口・動機をくわしく書かない。子どもが犠牲になる事件、実在の事件をなぞる話は書かない（2026-11-22 ユーザーの「事故や事件、突然死に絞る」で、他殺を入れることにした）。
10. 現代の日本（2020 年代）の話にする。実在の人名、病院名、商品名、細かい地名は書かない。
11. `{大切な人}` と書くと、その人にとって身近な人（妻、夫、娘、息子、母、孫、友人など）に置き換わります。誰に置き換わっても通じるように書いてください（「{大切な人}が湯呑みを置く」は可、「{大切な人}の白いひげ」は不可）。使うのは 1 件につき 2 か所まで。使わなくてもよい。
12. `{呼び名}` は、{大切な人}がその人を呼ぶときの呼び方（あなた、お父さん、おばあちゃん、名前など）に置き換わります。`with: true` の場面の、かぎかっこの中だけで使えます。
13. 同じ担当の中で、時刻（早朝・昼・夕方・深夜）、季節、年齢、場所、`aware`、最期の速さ（一瞬／数時間／数日かけて）がかたよらないように散らす。
14. `note` は「です・ます」ではなく「だ・である」で、ふつうの言葉で書く。「〜を行う」「〜において」「〜することができる」は使わない。

## ファイルと点検

- 出力は JSON の配列 1 つ。UTF-8。コメントや末尾のカンマは入れない。
- 書き終えたら、必ず点検スクリプトを通し、エラーが 0 になるまで直す。

```bash
python3 data/validate.py data/causes/<ファイル名>.json --prefix <接頭辞> --count <件数>
```
